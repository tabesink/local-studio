# ID-A — Render LightRAG Input

Parent: [[ID-A LightRAG Indexing Contract]]

**Question:** How should P5 turn Source Blocks into LightRAG input without losing evidence identity?

### Decision

Implement `render_lightrag_input(source)` as a deterministic renderer over P4 Source Blocks. It emits marker text with one `CE_SOURCE` header and one `CE_BLOCK` marker before each block's canonical Markdown. The rendered string is submitted to LightRAG and hashed, but not persisted as a product entity.

### Why

| Bad | Good |
| --- | --- |
| submit parser-native JSON | submit Context Engine Source Blocks |
| use LightRAG chunk ids for evidence | use `CE_BLOCK` ids generated by Context Engine |
| persist rendered text to debug | store only deterministic hash and safe state |
| include image bytes | include figure caption text already in Source Blocks |
| let render order depend on DB incidental order | sort by `source_order` |

### Contract Sketch

Patch F-005 spec before code if this grammar changes:

```text
[CE_SOURCE schema=1 source_id=<source-id> sha256=<original-sha256>]

[CE_BLOCK id=<source-block-id> order=<source-order>]
<canonical_markdown>
```

Allowed block metadata in marker grammar should be closed and deterministic. Keep page/section only if the fixture proves it does not break marker preservation and the spec captures escaping rules.

### Implementation Order

```text
1. Load Source Document and Source Blocks in source_order.
2. Reject if source is not prepared or has zero blocks.
3. Emit CE_SOURCE header.
4. Emit one CE_BLOCK marker before each block.
5. Normalize line endings.
6. Return rendered text + SHA-256 hash.
7. Never write rendered text to DB/logs.
```

### Red Flags In PR

- Function reads private original files instead of `source_blocks`.
- Function calls Docling/Reducto.
- Function stores rendered text in `source_documents`.
- Marker includes unescaped freeform labels without a grammar.
- Tests assert only hash exists, not exact rendered output.

### Tests

- Same Source Blocks produce same rendered text and hash.
- Changing block order/content changes hash.
- Empty/non-prepared source is rejected safely.
- Render output contains every Source Block id exactly once.
- Safe log/DTO scan proves rendered text is not exposed.

### One-line Summary

P5 indexes deterministic Source Block marker text; `CE_BLOCK` is the bridge from LightRAG text back to exact evidence.
