# Architecture Decision Records

Create an ADR when a Context Engine decision has meaningful alternatives, changes a boundary/contract/security posture/runtime/data model/deployment model, or is costly to reverse.

## Naming

Use `ADR-###-short-title.md`.

## Required Sections

- front matter with `id`, `title`, `status`, `date`, and `owner`;
- context;
- decision;
- options considered;
- consequences;
- migration/rollback;
- validation;
- related specs/contracts.

Small non-ADR decisions belong in `specs/00-governance/decision-log.md`.
