# Agent Toolkit

These prompts and checklists make the repository workflow repeatable across coding agents.

## Use order

1. Root `AGENTS.md` is binding.
2. Use a prompt from `prompts/` for the stage you are in.
3. Complete the matching checklist before moving to the next stage.
4. Record decisions in the feature documents—not only in chat history.

## Guardrail

Prompts assist the workflow; they never override source-of-truth documents, code review, security policy, or human approval.
