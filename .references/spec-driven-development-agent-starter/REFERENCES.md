# Reference Notes

This starter is informed by the following public material:

1. Microsoft Tech Community — *Spec-Driven Development for AI-Enabled Enterprise Systems* (May 18, 2026). The article frames specifications as a layered, modular source of truth across business/domain, architecture, implementation components, contracts, workflows, and AI-enabled systems.
2. GitHub Spec Kit — open-source toolkit and workflow for constitution → specify → plan → tasks → implement → verify/converge. This starter is tool-neutral but intentionally compatible with that flow.

This package adds practical enterprise-oriented templates for:
- contract/version management;
- AI capability specifications and evaluation;
- security/privacy/observability;
- traceability from need to evidence;
- coding-agent operating rules.
