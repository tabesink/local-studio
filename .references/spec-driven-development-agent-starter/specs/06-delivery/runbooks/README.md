# Runbooks

Create a runbook for any recurring operational action or high-impact failure mode.

Suggested file name: `RB-###-short-name.md`.

Each runbook must state:
- when to use it;
- prerequisites and authorization;
- safe step-by-step actions;
- expected observations;
- stop/escalation conditions;
- rollback or recovery;
- audit/evidence to record;
- owner and review date.

Do not turn a runbook into a substitute for automated reliability work. Automate repeated, safe, high-confidence actions where justified.
