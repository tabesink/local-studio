# Architecture Decision Records

Create an ADR when a decision:
- has meaningful alternatives;
- changes a boundary, contract, security posture, runtime, data model, or deployment model;
- is costly or difficult to reverse;
- will otherwise be repeatedly debated.

Suggested name: `ADR-###-short-title.md`.

## ADR template

```md
---
id: ADR-001
title: <decision>
status: proposed
date: YYYY-MM-DD
owner: <role>
---

# ADR-001 — <decision>

## Context
## Decision
## Options considered
## Consequences
## Migration / rollback
## Validation
## Related specs/contracts
```
