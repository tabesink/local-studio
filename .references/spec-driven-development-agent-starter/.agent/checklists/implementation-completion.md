# Implementation Completion Checklist

- [ ] All approved tasks complete or explicitly deferred.
- [ ] Acceptance criteria have actual evidence.
- [ ] Tests named in the test plan ran and results are recorded.
- [ ] Contract changes are documented and compatibility reviewed.
- [ ] Database/data changes have migration and rollback/compensation evidence.
- [ ] Authorization, input validation, and audit requirements are covered.
- [ ] Logs/traces/metrics are safe and usable.
- [ ] AI evaluations completed where applicable.
- [ ] Documentation matches the delivered behaviour.
- [ ] Implementation deviations are approved and recorded.
- [ ] Feature register and traceability matrix are updated.
- [ ] No secrets/private sensitive data were added to code, docs, fixtures, or logs.
