# Agent Prompt — Specify

Create or repair a feature specification before implementation.

1. Read `AGENTS.md`, governance, product, contracts, and the relevant code.
2. Use `specs/04-features/_template/spec.md`.
3. State the user outcome before implementation details.
4. Write clear in-scope and out-of-scope boundaries.
5. Include roles, behaviour rules, primary/exception flows, contracts, NFRs, acceptance criteria, open decisions, and risks.
6. Every acceptance criterion must be observable and testable.
7. Do not make undocumented business policy choices. Add an open decision with its owner.
8. Update `specs/07-traceability/feature-register.md`.

Finish with a change summary listing all docs created/updated and every unresolved decision.
