# Document control

## Status meaning

- `draft`: informational only.
- `proposed`: review and backend-contract approval required before implementation.
- `approved`: implementation authority.
- `implemented`: evidence exists in code/tests.
- `superseded` / `archived`: historical only.

## Change rule

A behaviour change updates the active feature spec, impacted contracts, test plan, acceptance evidence, and traceability matrix in the same change.

## Evidence rule

`Verified source` means commit-pinned Smart Composer code was inspected. `Target decision` means the intended Context Engine result is prescribed here. `Requires runtime validation` means no claim is made until a running target proves it.
