# Package Map

```text
README.md                         # starting point and review boundary
AGENTS.md                         # binding coding-agent rules
SOURCE_PIN.md                     # commit and source URLs
COPYING_AND_ATTRIBUTION.md        # MIT-source handling rules
specs/
  00-governance/                  # rules and decisions
  01-product/                     # target outcome and roles
  02-architecture/                # source map and target boundaries
  03-contracts/                   # proposed Context Engine contracts
  04-features/                    # one folder per delivery slice
  05-quality/                     # security, tests, performance, observability
  06-delivery/                    # migration and release process
  07-traceability/                # feature and source mapping
```

A coding agent starts with `AGENTS.md`, then the relevant feature folder, contracts, architecture, and current Context Engine code.
